# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - Initial Release

### Added
- Core transaction logging functionality (Title, Amount, Category).
- Segregation of records into Inflow and Outflow types.
- Live Balance Card displaying Net, In, and Out totals.
- Reverse-chronological transaction feed.
- Swipe to delete gesture for easy transaction removal.
- Pitch-black monochrome aesthetic with edge-to-edge UI.
- Custom typography integration (Google Sans Flex).
- Local offline data persistence using Room.
